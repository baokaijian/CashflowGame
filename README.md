# 现金流游戏 · 中国本土版

从“老鼠赛跑”走向财务自由的浏览器回合制游戏。用中国本土职业、投资机会与生活事件，模拟现金、资产、负债、家庭与精力之间的取舍。

**[在线游玩](https://baokaijian.github.io/CashflowGame/)** · [完整文档](docs/README.md) · [当前已知边界](docs/已知边界.md) · [使用许可](LICENSE)

## 开始游戏

直接打开在线版，或下载仓库后打开 `index.html`。本地开发建议在根目录启动静态服务：

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080`。游玩无需安装 Node、npm 或构建工具；需要支持 `color-mix()` 和 `:has()` 的现代浏览器。在线版、本地服务和直接打开文件各有独立存储，存档不自动互通。

启动时自动读取本地存档并续局；没有存档则显示新游戏设置，开局页及游戏内均不提供备份、导入或手动恢复选项。选择规则、模式、玩家和梦想后开始游戏，依次掷骰、处理事件、结束回合。游戏内菜单保留财务、贷款管家、玩家交易、复盘和规则说明。多人为同一设备轮流操作；界面支持响应式布局、明暗主题和内外圈切换。

- 空格：无弹层时掷骰或结束回合。
- Esc：关闭允许关闭的弹层；必须处理的事件不能直接跳过。

## 模式与目标

| 模式 | 时间与退休 | 结束方式 |
|---|---|---|
| 年龄模式 | 20 岁开始，各玩家独立计龄；不启用单人退休规则 | 达成胜利条件，或所有仍在局内的玩家到 65 岁后按账面净资产排名 |
| 单人模式 | 固定 1 人，20 岁开始，61 岁退休 | 成就记录后继续至 65 岁并评级；破产或认输可提前结束 |
| 无限模式 | 无终龄，年龄仍随结算增长 | 达成胜利条件 |

| 规则 | 101 基础版 | 202 进阶版 |
|---|---|---|
| 出圈门槛 | 被动收入严格大于总支出 × 1.5 | 被动收入严格大于总支出 × 2.5 |
| 投资 | 小额理财、大额置业 | 杠杆交易、大额现金流，另有做空与期权 |
| 开局 | 职业卡 | 职业卡与随机投资组合 |
| 合作 | 独立购买 | 可联合购买；单人由机构承接合作 |
| 行情卡 | 16 张 | 42 张，抽满 25 张重洗 |
| 自由圈 | 购买企业与梦想 | 另有特许经营、多人买断玩法 |

当前包含 **12 个职业、10 张组合卡、6 个梦想、7 家自由圈企业**，以及合计 **132 张投资、行情与意外支出卡**。

出圈获得一次性资金奖励，之后按当前持仓领取收入，继续承担生活费和债务。购买自己的梦想，或累计新增自由圈企业月收入达到 ¥20,000，可达成胜利条件；202 还支持最后存活玩家获胜。单人将这些记录为成就并继续人生。累计企业成就与当前可领取分红分开，卖掉资产就停止对应收入。详见 [单人规则](docs/单人模式设计说明.md)、[自由圈](docs/自由圈收益归属.md)。

## 收支与年度结算

**月净现金流 = 全部收入 − 生活及其他支出 − 实际月供。每经过一个发薪日或分红日，结算一年并长一岁。**

内圈 3 个发薪日，外圈 4 个分红日；每次结算预演 12 个月的收支与贷款本息，然后合计入账。年中结清就停止扣供，最后一期只收剩余本息，因此年度净额不一定等于当前月净额乘 12。还清贷款增加净现金流，新借款增加未来利息或月供；房产项目利息已从房租收入扣除，不重复计入个人月供。

一趟移动经过两个结算格就分别结算两年，没有经过就不长岁、不补发。20→65 岁正常结算 45 年；终龄停止移动，年度亏损先处理，终局不额外结算。详见 [时间规则](docs/结算步长与发薪日密度.md)、[贷款与生活费用](docs/持续生活预算与还贷.md)。

发薪日和分红日日志会显示年净额较上次的变化，并直接列出主要原因，例如「子女养育费年度支出减少 ¥840」。展开「年度对账明细与变化原因」先看逐项差额，再看完整账单、年内各月净额及每类贷款的还款经过，并区分本年实际入账与长岁后下一年的预计变化。对账基准随本地进度自动保存；更新前没有明细的历史不反推，从更新后的第一次结算开始记录。

复盘诊断区分历史记录与当前账本：健康危机依据精力归零机制说明，当前维护与恢复用于评估后续经营；现金安全垫使用当前余额，个人贷款已结清不会写成全程零负债。建议根据现金、精力和实际机会安排动作，不要求固定每轮投资或固定间隔休假。详见 [复盘诊断与建议](docs/复盘诊断与建议.md)。

自动存档为一个浏览器本地槽，启动时自动读取，无记录则显示新游戏设置。**不提供手动备份、文件导入、恢复进度或历史核对入口。** 复盘 Markdown / JSON 仅供阅读分析，不能用于续局。

保存失败会提示并保留上次成功记录，后续操作继续尝试自动保存；不能保证异常关闭前的最后一步已保存。内存日志最多 300 条、自动存档日志 80 条、财富轨迹 60 点，清理浏览器数据后无法从游戏界面找回进度。

旧档的自动迁移继续生效：唯一成交凭据修复成本，缺少随机状态的旧档稳定接续未来序列。历史核对记录继续兼容保存；缺少依据的信息不猜测补账，见 [旧档说明](docs/旧档核对与修复.md)。

## 当前边界与平衡

已完成的修复排期已清理，当前说明集中在 [已知边界](docs/已知边界.md)。主要仍有限制的是：

- 房产项目通常持有期付息、出售还本，不逐月摊还；没有完整税费、租客或订单撮合市场。
- 配偶收入、真实社保账户、车辆更新选择、企业个体维修及机构自主议价尚未完整建模。
- 征信仅使用本局借款行为；期权、做空是简化工具，没有真实保证金体系。
- 无联网房间、云同步或自主 AI 对手；破产出局后不能重新入场。

当前 288 个固定策略情景全部正常结束；202 在这些情景中比 101 更难。核验不是最优策略证明或总体玩家胜率，详见 [当前平衡报告与数据](docs/游戏平衡核验.md)。

## 结构与开发

```text
index.html      页面入口与按内容版本加载的资源
css/            主题、组件、棋盘与响应式样式
js/data-*.js    职业、配置、棋盘与卡片
js/engine.js    状态、账本、结算、估值、贷款、迁移与胜负
js/engine-actions.js  买卖、借还、合作与事件动作
js/save-state.js      完整存档校验、编解码和恢复
js/ui-*.js      通用界面、游戏操作、事件弹层与复盘
js/main.js      启动检查与全局交互
test/          Node 回归脚本与浏览器行为探针
tools/         标定、平衡核验与资源版本工具
docs/          当前专题说明、模型边界与许可说明
```

静态 HTML/CSS/JavaScript，无后端和构建依赖；脚本按配置 → 引擎 → 动作 → 存档 → 界面 → 启动顺序加载。详见 [结构与维护](docs/游戏结构与维护.md)。

```bash
node test/loan-cashflow.js
node test/asset-transactions.js
node test/save-recovery.js
node tools/version-assets.js --check
```

全部验证命令与覆盖范围见 [测试目录](test/README.md)。修改运行资源后执行 `node tools/version-assets.js` 更新内容版本；改动规则时同步对应文档。价格工具可能改写数据，先阅读 [标定说明](docs/出圈门槛与投资回报标定.md)。
