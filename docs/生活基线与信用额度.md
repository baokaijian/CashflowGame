# 生活基线 · 自由圈账本 · 信用额度

> **时间规则更新（2026-09-22）**：现行规则为每个发薪日 / 分红日结算一年并长一岁，玩家独立计龄；回合不长岁，无积欠、略过或退休 / 终局补结。本文涉及旧时间口径和旧测试数量的内容保留为历史记录，当前实现以 [发薪日、年龄与年度结算](结算步长与发薪日密度.md) 为准。

> 这三条规则解决的是同一个问题的三个面：**钱流进来的速度可以很快，但它流出去的速度从来不会自动变慢。**
>
> ① 生活基线 —— 门槛不随负债消失而崩塌
> ② 自由圈账本 —— 顺流层也要扣支出，也一样会破产
> ③ 信用额度 —— 借钱的上限由收入与征信决定，不再是「想要多少有多少」

验证脚本：`node test/life-baseline-credit.js`（**60 项断言**，退出码 0 = 全通过）

## 一、生活基线：房贷还清 ≠ 住房成本归零

### 核心规则

**住房支出 = max(房贷月供, 住房基线)**，两者**不叠加**。

```
住房基线 = 基础工资 × LIFEBASE.housingRate(0.11) × 人生阶段系数(lifeCoef)
```

- 有房贷时按 **房贷月供** 计 —— 与改造前的数据完全一致，**开局平衡分文未动**
- 房贷还清后按 **住房基线** 计 —— 成本不归零
- 二者取大者，所以永远不会出现「房贷月供 + 基线」的双算

### 现实依据

1. **自有住房的成本从未归零。** 物业费、取暖、维修、家电置换、装修折旧是持续的；若要换房或租房，成本更高。职业卡里房贷月供约占工资 **10%—12%**，与真实社会的住房负担同量级。
2. **财务自由的定义是「被动收入覆盖你想要的生活方式」**，而不是「被动收入覆盖你负债最少时的开销」。若门槛随负债消失，规则就会奖励「把生活压到最低」——这与本作的财商教育目标完全相反。
3. **还清贷款改善的是现金流，不是生活成本。** 现实中房主不会因为还清房贷就搬去住更小的房子，省下的月供通常转为改善性支出或其他资产配置。

### 调整后的效果

实测（`test/life-baseline-credit.js` 第 ① 节）：

| 职业 | 房贷月供 | 门槛（有房贷） | 门槛（还清后） | 其中住房基线 |
|---|---|---|---|---|
| 三甲医院医生 | 1,900 | 9,211 | 7,145 | 1,234 |
| 软件工程师 | 700 | 2,710 | 2,138 | 458 |
| 货运司机 | 400 | 1,562 | 1,196 | 234 |
| 小区保安 | 300 | 1,058 | 728 | 150 |

货运司机还清全部负债后：把 `housingRate` 关掉门槛会掉到 **¥962**，有基线时是 **¥1,196** —— **24% 的崩塌被挡住了**。同时月结余只增加 ¥366（小于房贷月供 ¥400），说明「住房成本只是换了形态，不是消失了」。

### 前后差异

| | 改造前 | 改造后 |
|---|---|---|
| 房贷还清后 | 住房支出 → **0**，门槛从 ¥3,000 掉到 ¥400 | 住房支出 → **住房基线**，门槛不再崩塌 |
| 出圈的难度 | 随时间**递减**（还清贷款就变简单） | 随时间**稳定**（必须真的积累被动收入） |
| 「压低生活」是否有利 | **有**（门槛跟着降） | 否（门槛有地板） |
| 开局平衡 | — | **完全不变**（有房贷时缺口恒为 0） |

### 为什么只对住房设基线

生活性支出已经由 `LIFE_STAGES` 的人生阶段系数与消费升级规则管着，再加一条会变成**双重计费**。住房是唯一一个「会随负债消失而彻底归零、但现实中绝不归零」的科目。

## 二、财务自由圈：顺流层同样有账本

### 核心规则

```js
自由圈收入（月度） = ftMonthly(p) = p.ftBase + Σ(企业现金流)
自由圈支出（月度） = 生活性支出 × LIFEBASE.freeTrackMult(1.35) + 仍在还的贷款月供
分红日入账        = (收入 − 支出) × 12 × 经过的年数
```

**工资薪金个税不再计** —— 出圈意味着主动收入退出生活，工资既然不入账，与工资绑定的个税也一并停征（现实里财务自由后改按资产收益计税，本作简化为不计）。若只停收入不停税，会出现「为不存在的工资交税」的荒谬口径。

### 现实依据

1. **生活方式膨胀同样发生在财务自由之后**：换更好的房子、请人打理、更高标准的医疗与出行——这些不会因为「不用上班」而减少，反而因为时间变多而增加。
2. **富人的风险不是买不起，而是养不起。** 原版《现金流》的快车道同样设有生活支出，正是这个意思。
3. **顺流层不是安全区。** 只发钱不扣支出，会让「财务自由」变成一个绝对安全的终点，游戏的张力瞬间消失。

### 调整后的效果

实测（软件工程师，出圈当轮）：

| 项 | 金额 |
|---|---|
| 出圈资金 | ¥311,700 |
| 自由圈收入（分红） | ¥3,117 / 月 |
| 自由圈支出 | ¥1,881 / 月（生活 ¥851 + 贷款 ¥1,030） |
| **月结余** | **¥1,371**（年 ¥16,452） |

对照旧口径：旧版直接按 **¥3,117** 入账，**差额 ¥1,881/月** 是完全没有的支出侧，一年就是 ¥22,572。

**「可能破产」的真实路径**：刚出圈时被动收入只比门槛高一点点，生活档次一升级就所剩无几；此时若遭遇税务稽查 / 诉讼 / 离婚这类大额事件，现金不足且无法变现，就会破产。

### 前后差异

| | 改造前 | 改造后 |
|---|---|---|
| 顺流层支出 | **无** | 生活性支出 × 1.35 + 贷款月供 |
| 现金增长 | 无上限（实测期末中位 **¥100 万+**） | 与经营能力挂钩 |
| 能否破产 | **不可能** | 可以（回归里已构造出该路径） |

## 三、信用额度：收入决定你能借多少

### 核心规则

```
① 收入授信（在职）= min(年收入 × 1.2, 硬顶 ¥600,000) 且受 DTI 约束
                    再乘「征信系数 × 就业系数」
② 资产抵押（应急）= 可变现资产净值 × 50%，不受 DTI 约束

授信总额 = max(①, ②)
本次可借 = 授信总额 − 当前信用贷余额
```

**负债收入比红线**：所有贷款月供之和 ≤ 月收入的 **55%**（`CREDIT.maxDTI`）。

### 现实依据（国内消费贷 / 信用贷的实际风控口径）

1. **DTI（负债收入比）**：月还款额不得超过月收入的 50%—55%，超过即被认定为「还款能力不足」。这是最硬的一条红线。
2. **授信倍数**：纯信用类贷款（无抵押）上限通常在年收入的 1—2 倍之间，与抵押类房贷（可达年收入 5—10 倍）完全不同。
3. **第一还款来源**：无稳定收入者基本无法获批——银行无法核实还款来源。
4. **征信记录**：从无还款记录的「白户」反而授信谨慎；有破产 / 长期逾期记录者在征信恢复期内不予授信，恢复后额度也大幅折价。
5. **抵押融资是失业者的救命通道**：失去收入后，房产抵押、存单质押是主要的应急融资渠道——银行看的是抵押物价值，不是工资流水。
6. **退休额度折半**：靠养老金的人即使获批，额度也远低于在职时期。

### 调整后的效果

实测开局授信（12 职业）：

| 职业 | DTI | 授信总额 | 约束来源 |
|---|---|---|---|
| 三甲医院医生 | 25% | ¥171,072 | 收入侧（年收入 × 1.2） |
| 执业律师 | 25% | ¥97,200 | 收入侧 |
| 货运司机 | 24% | ¥32,400 | 收入侧 |
| 汽修技师 | **47%** | **¥14,400** | **DTI 侧**（仅剩 ¥160/月 空间） |

**汽修技师是最说明问题的一例**：它 DTI 已 47%，DTI 空间只剩 ¥160/月，所以授信被压到 ¥14,400 —— 而收入侧本可以给 ¥28,800。**收入高不等于能借得多，还要看已经欠了多少。**

### 拒绝授信的各种情形

| 情形 | 结果 | 依据 |
|---|---|---|
| 失业 + 无资产 + 无收入 | **拒绝** | 既无第一还款来源也无抵押物 |
| 失业但有存款 / 房产 | **可借**（额度 = 抵押物 × 50%） | 抵押融资不受就业状态影响 |
| 退休 | 可借但收入侧系数 × 0.5 | 养老金收入远低于在职 |
| 破产后 10 个回合内 | **拒绝** | 征信恢复期 |
| 破产记录（恢复期后） | 可借但额度 × 0.45 | 征信折价 |
| 入不敷出累计 6 个月 | 可借但系数 × 0.62 | 现金流管理能力影响征信 |
| 额度用尽 | **拒绝** | DTI 已触红线 |

### ⚠️ 一个容易被误判成 bug 的真实行为

**已借余额可以高于「当前」授信额度。** 授信额度随状态变化（失业 ×0.35、退休 ×0.5、
入不敷出 / 破产再打折），而你**已经借出来的钱不会消失**。

> 例：在职时借满 ¥3 万，随后失业 → 新的额度可能只剩 ¥1 万，而余额仍是 ¥3 万。

这正是现实中的**银行降额**（授信收缩，存量贷款照旧计息），不是账目出错。
所以回归里的断言口径是「**余额 ≤ 该玩家历史上任何时刻的额度**」——
它守的是「借钱这一步绕不过额度校验」，而不是「余额永远低于当前额度」。

### 前后差异

| | 改造前 | 改造后 |
|---|---|---|
| 额度 | **无限** | min(年收入 × 1.2, DTI 空间) × 系数 |
| 期限 | 无限期、只还息 | 不变（仍随借随还） |
| 无收入者 | 照借不误 | 拒绝（除非有抵押物） |
| 杠杆螺旋 | 回归里 AI 曾滚到 **¥5,700 万** 且永不破产 | 回归实测压到 **¥171,072**（医生的上限） |

## 四、连带修掉的四个缺陷

这三个改动让「失业」这条路径从「几乎必死」变得可走，过程中暴露并修掉了四个**真实缺陷**（都不是调参能解决的）：

### ① 失业期间仍在扣工资薪金个税

`refreshLife` 只在**退休**时把 `taxesCur` 归零，失业时仍按基础工资计税 —— 出现「没有收入却还在交税」，并把失业期的缺口整体放大了（护士：¥360/月）。

现实依据：没有工资薪金所得，就没有工资薪金个税。**已修**。

### ② 失业期间生活支出分文不减

失业后家庭会主动砍掉非必要消费（外食、娱乐、推迟大额置换），但房贷、子女教育、基本生活很难砍 —— 所以不是腰斩，而是砍掉约 1/4（`UNEMPLOYMENT.lifeCut = 0.75`）。

不加这一条会出现荒谬结果：收入归零而支出分文不减。**已修**。

### ③ 结算跨越了「收入状态突变」——高估缺口 2—3 倍

这是最隐蔽的一个。方案 A 的结算是「**当前**月度结余 × 经过的年数」，而 `due` 年内的收入状态可能已经变过：

> 实测（护士 · 种子 20260920）：失业前的 1 年 + 失业后的 2 年，**全部按失业后的缺口计算**，
> 真实缺口约 ¥1.5 万被算成 **¥4.6 万**，超过手头现金，直接把人逼到破产。

**修法**：失业时先按「在职」口径把未结算周期**结清**（`E.settleAtBreak`），再切换状态。这样「未结算周期」永远不会跨越突变点。

### ④ 65 岁还在「求职期」，连养老金都领不到

`isJobless` 的判定先于退休，于是「56 岁被裁 → 求职期跨到 61 岁」的人，**退休后工资仍为 0，养老金也领不到**，最后以「失业」之名破产。

**修法**：退休时清除求职状态 —— 到了退休年龄就不再求职，直接领养老金。**已修**。

## 五、平衡影响（实测）

| 指标 | 结果 |
|---|---|
| 开局平衡（有房贷时） | **完全不变**（住房缺口恒为 0） |
| 出圈门槛（还清贷款后） | 比旧版高 20%—26%（住房基线顶上） |
| 顺流层年度支出 | 从 **0** 变为「生活 × 1.35 + 贷款」 |
| 单局最长信用贷 | 从 ¥5,700 万 → **¥17 万**（= 授信上限） |
| 单人 101 · 最长局 | 汽修技师（最弱职业）**跑满 45 轮**，评级 C |
| 多人 202 · 4 人 | **跑满 180 回合，4/4 存活** |
| 不变式 | 全程现金非负 · 无 NaN · 无卡死 · **信用贷余额从未突破授信上限** |

## 六、仍未解决的缺口

1. **退休也是一次收入突变**，但没有做突变点结算（失业做了）。影响较小（养老金替代率 45%，不是归零），且退休只发生在单人模式的最后 4—5 轮。
2. **「一次结多年」的估算仍然是近似**：结算用「当前结余 × 年数」，只在**失业**这一个突变点做了修正。若期间发生涨薪 / 降薪 / 还清某笔贷款，仍有小额误差。
3. **生活基线的绝对水平仍是标定值**：`housingRate = 0.11` 来自「职业卡房贷月供占工资 10%—12%」的实测反推，再往上就没有更硬的锚了。
4. **抵押物估值是静态的**：房产按「已付首付」计，不随房价涨跌、不折旧。现实中抵押率与评估价都要动态调整。
5. **信用额度不含「多头借贷」识别**：现实中银行能看到你在其他机构的总负债；本作只看玩家自己的账本（对单机游戏来说这已经是等价的了）。
