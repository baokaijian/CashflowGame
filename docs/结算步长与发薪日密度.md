# 结算步长与发薪日密度

> **本文是决策记录**：结算步长与发薪日密度必须**搭配**改动，本文记录三组搭配的对照实验
> 与最终决策（2026-09-22 二次定稿：**一个结算格 = 一年（积欠模型）+ 内圈 3 个等距发薪日**）。
> 可复跑：`node test/payday-settlement.js`（55 项）、`node test/payday-trigger.js`（90 项）。

## 一、最终口径（定稿）

| 项 | 规则 |
|---|---|
| **结算步长** | **一个结算格 = 恰好 1 年**：每经过一个发薪日 / 分红日，结算【最旧的 1 个未结年份】 |
| **入账** | `年结余 × 1`（年结余 = 当前月结余 × 12；不逐年回溯年龄曲线） |
| **摊还** | 每笔 12 期（领 1 年就还 1 年） |
| **积欠** | 没踩到结算格的年份由 `p.settledAge` 记账积欠；后续结算格逐个结清，收入突变（失业 / 退休）与终局则**一次结清全部积欠**（不丢年，实测覆盖率 100%） |
| **发薪日密度** | 内圈 **3 / 24 格，等距 2 / 10 / 18**（每轮平均经过 ≈0.44 个）· 外圈 **4 / 24 格**（≈1.17 个，密度 > 1 → 略过是常态） |
| **多格** | 同一次移动跨 N 个结算格 → 结 N 年（每格各 1 年）；积欠不足时第 N+1 个记「本年已结」略过（不给未活过的年份发薪） |
| **零格** | 不结算、不推进、日志不出现发薪记录 |
| **总年数** | 一生累计结算 = 年龄跨度 —— 积欠由突变点 / 终局兜底，收入不丢年 |

**等距的结构性副产品**：相邻发薪日间隔 8 格 > 单粒骰子上限 6 步 →
常态下一个回合**最多跨 1 个**发薪日；「一回合跨多个」只在银翅膀（2 粒骰，≤12 步）时发生，
且最多跨 2 个。

## 二、三组搭配的对照（为什么是现在这个组合）

| 搭配 | 覆盖率 | 出圈率 | 结局 |
|---|---|---|---|
| 每格 1 年 + 3 发薪日，**无积欠兜底**（第一步） | 44.4% | 几乎不可能 | 从未上线 |
| 每格 1 年 + 7 发薪日（1.02 个/轮） | 101.5% | 71% | 上线一天后回滚（结算太频繁） |
| 方案 A（结清积欠）+ 3 等距发薪日 | ≈100% | 57% | 上线一天后回滚（玩家读不懂） |
| **每格 1 年 + 积欠兜底 + 3 等距发薪日（定稿）** | **100%** | **39%**（带宽内） | **当前版本** |

方案 A 被回滚的直接原因：玩家（用户）对两件事提出质疑 ——
「跨 2 个发薪日为什么只结 1 笔」「隔几轮踩 1 个发薪日为什么一次结 3 年」。
即便日志与弹层都给出「一次结算（覆盖 X—Y 岁共 N 年）+ 年结余 × N」的自证算式，
**多年合并结算仍然反直觉**。定稿口径把对应关系摆到明面上：
**经过几个结算格 = 结几年**，每笔 1 年、逐笔入账、逐笔摊还。

积欠兜底解决了第一步「覆盖率 44%」的死穴：没踩到发薪日的年份不是丢了，
而是记在 `settledAge` 的落后量里，由失业 / 退休突变点与终局结清 ——
突变点结清本身是引擎不变式（未结算周期不得跨越收入状态变化，否则会把
在职年份按失业口径算错），这里只是让它同时承担「兜底」职责。

## 三、难度影响（定稿口径的实测）

同一 AI、6 种子、12 职业、72 局：

| 指标 | 方案 A + 3 等距发薪日 | 每格 1 年 + 积欠兜底（定稿） |
|---|---|---|
| 出圈率 | 57%（41/72） | **39%（28/72）** |
| 出圈年龄中位 | 57 岁 | **60 岁** |
| 收入到达节奏 | 每个发薪日一次结清全部积欠（笔大、间隔密） | 每个发薪日 1 年 + 突变点 / 终局的积欠兜底（笔小、更慢） |

出圈率下降 18 个百分点的原因：**收入到达变慢**（发薪日只发 1 年，
积欠要等到突变点 / 终局才兑现），中期可投资现金变少。
仍在 25%—80% 验收带内；若想回调难度，动 `YIELD.safetyMargin`
（调低更容易、调高更难）—— 它是独立标定过的难度旋钮，不该由结算口径的连带影响绑架。

## 四、边界情形（都有断言）

1. **跨 0 个结算格** → `settled === null`，现金与 settledAge 都不动，不产生提示。
2. **积欠 = 0 时踩到结算格** → 记一笔「略过」并明说（提示 kind = `already`），
   不静默；来源：外圈密度 > 1、或突变点刚结清后同岁再踩。
3. **同一回合跨多格且中途还清贷款** → 各笔月结余可以不同（第 1 笔摊还还清贷款后
   月供消失），合计 = 各笔之和，不是「单年 × N」。
4. **摊还途中负债被还清** → 它的期数停在结清那一刻，期数 < 12 属正常。
5. **破产路径不做终局结清** → 破产是「现金流断裂」的即时判定，积欠天然残留。
