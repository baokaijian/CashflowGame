# 发薪日、年龄与年度结算

2026-09-22 更新：用户明确要求 **每经过一个发薪日，结算一年并长一岁**。
本规则替代此前的「回合长岁」「积欠」「本年已结略过」「退休或终局补结」方案。

## 当前规则

- 每位玩家以 `p.age` 独立计龄，从 20 岁起步。
- 内圈经过或停在发薪日，结算一年收支、摊还 12 期贷款，然后长一岁；外圈分红日相同。
- 本次入账 = 当前月结余 × 12；负值作为年度缺口，先走补款、借贷、变卖或破产流程。
- 一次移动经过 N 个结算日，逐笔结算 N 年、长 N 岁。每笔重新计算账本，前一笔还清贷款或跨过年龄阶段会影响下一笔。
- 未经过结算日、结束回合、求职或休养均不长岁、不结算，不累积待结年份。
- `round` 仅表示行动轮次。求职、休养、期权到期、近期借贷记录仍按回合计时。
- 资产的 `heldYears` 随持有者实际年度结算推进；市场周期以场上最长的已推进人生年数为时间轴。

## 退休和终局

单人模式中，60→61 岁的一年仍按在职账本结算，然后切换养老金；61→62 岁起使用养老金账本。
即使一回合跨过多个结算日，也会在中间正确切换，无额外补结。

年龄 / 单人模式到达 65 岁时，移动立即停止在该结算日。
最后一年的缺口与确认面板处理完，结束回合后完成人生结算。
从 20 岁走到 65 岁恰好结算 45 年，所需行动轮数不固定。
多人先到终龄者保留资产等待，不再行动、参与交易或受他人行情卡影响；所有仍在场的玩家完成后按净资产排名。
原有提前获胜条件、破产和认输仍有效。无限模式不受 65 岁上限约束。

## 棋盘与文案

内圈保持 24 格中的 3 个等距发薪日（2 / 10 / 18）；外圈保持 4 个分红日。
单骰最多跨一个发薪日，银翅膀双骰最多跨两个；密度只影响行动节奏，不再制造积欠或跳过。

日志、提示和确认面板共用 `landed.settled`，显示「结算 N 年（起始年龄→结束年龄）」及实际金额。
经过但未停留使用提示，停在结算日使用确认面板，亏损先使用缺口面板；展示不再执行结算。

## 存档

新档以 `timeVersion: 2` 和每位玩家的年龄保存。
旧档恢复时保留已有现金、贷款、年龄与待处理事件，从恢复点起执行新规则，绝不重新发放历史收入。
旧档的出圈年龄、历史快照年龄和资产持有年数仅迁移一次。
`settledAge` 保留为兼容镜像，`settleAtBreak` / `finalSettle` 保留兼容接口，但不再转移资金或摊还贷款。

## 验证与难度观察

- `node test/payday-settlement.js`：单次 / 多次、退休、终龄亏损、多人独立年龄、资产折旧与新旧存档。
- `node test/payday-trigger.js`：4,704 条路径和 12 局完整人生，逐笔核验 45 年，无遗漏、跳过或额外补结。
- `node test/time-unit.js`：年 / 月换算与每个结算日的贷款摊还。
- 其余职业、单人、长局、信用、估值、投资回报验证，以及浏览器中的年龄显示、确认、保存恢复与终局操作。

旧版以回合计算年龄的「40 岁前不超过 20%」指标仅保留为历史对照。
