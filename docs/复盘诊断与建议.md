# 复盘诊断与建议

核对日期：2026-10-02。实现见 [复盘界面](../js/ui-summary.js)。网页、Markdown 与 JSON 导出共用指标和诊断。

## 健康与经营

健康危机由游戏精力降至零触发，产生强制休养和持续医疗支出。回合自然恢复、资产持续维护、购买与求职等一次性投入共同影响精力；年龄及康复状态影响恢复能力。它不是随机触发的事件。

诊断显示已记录的危机次数，再列当前维护与自然恢复。维护大于恢复时，即使没有新增行动，精力也会持续下降；两者相等时，没有余量抵消额外投入；维护小于恢复时，仍需为新行动预留精力。康复期恢复减半会标注。

当前持仓和恢复能力不能证明过去每次危机的具体原因。经历过危机但已调整组合的玩家，不会被直接判为当前资产规模过大。建议先检查经营类型、规模协同、机构合同和维护余量，再决定是否扩张。起点休假只补充精力，不消除持续维护，不能保证固定每两三轮休假可持续。

## 账本与历史

- 现金储备诊断用当前余额与当前月支出，不拿历史现金峰值当作可用应急金。原有评分和等级仍可使用峰值指标，但描述明确说明峰值口径。
- 负债诊断显示当前个人贷款，信用贷利息只代表该产品。当前贷款结清不等于全程没有借款；房产项目融资已计入资产净收入，不重复扣月供。
- 出局后余额可能已清算，不据此断定退出前没有资产、净现金流为负或全部缺口来自失业。主动退出与破产分开描述。
- 投资放弃次数和资产类别数是核对提示，不能单凭这些数字判定决策错误或组合风险。缺失历史不补造；零次记录写作未记录。

## 建议的范围

健康、退出过程、结算缺口和当前现金缓冲优先提示；出圈缺口、机会筛选、融资及阶段目标结合当前状态说明。高评分仍需关注健康与安全垫，不承诺只有提速一项改进方向。

行动清单按资金、净收益、贷款和精力选择机会，不规定每轮成交笔数、固定休假间隔或固定还款金额。年龄工资峰值从现有曲线读取，回合数与结算年数区分；自由圈企业与梦想均属于目标选择。三个月现金储备是游戏建议参考，不是获胜条件。

消费档次由游戏财富与现金流等级决定，不保证卖出某一类资产即可降低。资产流动性与回报需按实际报价、兑付条件和交易机会核对。
