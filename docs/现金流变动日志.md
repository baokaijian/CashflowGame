# 现金流变动与年度对账日志

核对日期：2026-10-10。日志区分实际年度结算、当前月净额与下一年预期，使用同一套收支和贷款计划，不通过日志额外发钱。

## 直接看变化

- **当前月净现金流**：投资、卖出、借款、提前还本、就业、精力绩效、家庭或医疗变化影响账本时，记录原金额 → 新金额及差额。收入、生活及其他支出、个人贷款本息分别列出，不能把借款到账当作收入增加。
- **本次年度实际净额**：每个发薪日／分红日展示该年实结金额，与同一玩家上次实结比较。只有相邻年度且有完整凭据才作比较；旧日志缺失时不猜原因。
- **下一年预计净额**：按当前状态预演十二个月，贷款逐月扣本息。尚未入账，之后的投资或收支事件仍会改变它。年中结清贷款时，预计年净额可能改变而当前月净额不变。

摘要直接显示影响最大的三个科目：每项的原金额、新金额、收入／支出的涨跌幅，以及对净额的影响。右侧正数提高净额、负数降低净额；例如信用贷月息 100 → 75，支出下降 25%，月净额提高 25。即使总净额不变，抵消的收入与费用变化也会显示。完整明细保留其余科目及工资阶段、精力绩效、子女阶段和医疗预算等因素。

整体净额涨跌幅以 `净额差额 / 原净额绝对值` 计算，负净额基数也沿用此口径；原净额为零时不计算百分比。日志明确标记由盈转亏、由亏转盈或收支平衡，避免负基数显示反向涨跌。

## 年度账单的经过

展开年度对账可查看实际收入、生活支出和个人贷款本息的恒等式、逐项贡献、年内各月净额及每类贷款的还本经过。贷款尾款只扣剩余本息，结清后的月份停止扣供。

结算先按长岁前的账本结完该年，再推进年龄和家庭、摊还贷款并切换未来收入。摘要另列结算后下一年预计变化，例如 27→28 岁工资档位调整、子女成年支出下降、贷款结清；不能把这些变化计进刚发的那一年。

## 自动保存与边界

实时对比基准、年度凭据和日志摘要随本地进度保存。重复重绘或刷新不会追加相同变化、重复发薪或改写旧金额。旧档没有实时基准时，从读取后的当前账本开始记录；已经裁剪的日志不会凭空恢复。内存最多 300 条、本地存档最多 80 条，仍不是完整交易流水。

`Engine.recordCashflowChanges` 在界面状态刷新、移动前和回合结束时核对账本；每次实际年度结算则保存独立凭据并更新预期基准。`SaveState` 校验科目加总、差额及摘要；界面按文本转义资产名称与原因。见 [自动存档](存档保护与随机状态.md)、[年度规则](结算步长与发薪日密度.md)。
