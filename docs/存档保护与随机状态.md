# 存档、随机连续性与复盘

核对日期：2026-09-28；实现见 [save-state.js](../js/save-state.js)、[ui-game.js](../js/ui-game.js)、[ui-summary.js](../js/ui-summary.js)。

## 自动保存与完整备份

页面持续显示保存中、最近成功时间或失败。“保存与备份”提供重试、下载完整存档与导入，开局页也可以导入。

自动保存先序列化校验，再一次性写入 `localStorage`；失败不覆盖上次成功记录，也不把成功时间更新为当前时间。无法读取的记录不自动删除，可下载原始内容核对。重新开始若无法删除旧记录，保留内存对局并提示。

完整备份包含对局、玩家、资产负债、家庭、牌堆、待处理事件、行动和随机进度。下载不要求本地存储写入成功，但当前内存状态必须有效且在容量范围内。

## 导入流程与格式

1. 检查文件格式、版本、大小、金额、状态结构、对象深度及危险字段。
2. 在临时状态恢复随机源并迁移时间、家庭、资产等，校验账本及渲染，不修改当前对局。
3. 展示规则、模式、回合、玩家等预览；取消不切换。
4. 确认后先写本地记录，再切换对局；写入失败不切换，界面恢复失败则回滚原局和记录。

格式为 `cashflow-save`、版本 2；本地键仍为 `cf_save_v1`，兼容有效的旧版 v1 数据。文本上限 2,000,000 字符，玩家 1—6 人，树节点最多 150,000、嵌套深度最多 40；结构无效或版本不支持拒绝导入。开局配置和主题另行保存。

迁移不能重放现金。已锁定年度缺口、原牌堆和报价保持原值；缺失出生年、历史成本或融资凭据的处理见 [已知边界](已知边界.md)。未来月供及生活费用按当前规则计算，不补发或追扣历史。

## 随机状态和中断掷骰

职业、组合、牌堆、骰子与洗牌共用可保存的随机状态。没有指定种子也只在开局初始化一次；恢复后重新绑定牌堆随机源，包括 202 抽满 25 张行情重洗。期权编号使用可保存计数器，装饰骰子动画不消耗实际游戏结果。

掷骰先记录结果再播放动画。动画中断后继续执行已生成结果，执行完成清除待执行骰子并保存；不重新掷骰，也不重复经过发薪。旧档没有随机历史时只从恢复点建立序列，保留现有牌序并提示，不能反推出过去种子。

## 复盘与财富轨迹

复盘显示财富曲线、资产负债、社会等级、成就、人生评级及建议，并可导出 Markdown / JSON 报告。当前收入、支出和月净额按所在圈计算；自由圈不计停领工资，已售资产不继续产生收入。

每回合观察财富，按玩家自己的年龄合并：首个已知点独立保留，同龄后续只保留最新点；每次观察仍更新峰值。一次跨过多年未观察到的中间点不补造。超过 60 点时保留首点和最新 59 点；图表按年龄间距绘制，旧档历史不重算。

内存日志最多 300 条，自动存档最多保存最近 80 条；完整备份保留当时内存记录，不能找回已经截断的历史。复盘报告不是完整存档，不含可继续游戏所需的全部状态。

## 限制与验证

只有一个本地自动槽，没有云同步。清理站点数据、更换浏览器或地址会使旧记录不可见；离开页面会尝试写入，但无法保证异常退出前最后一步已落盘。导入要求存储可写；本地数据没有服务器防作弊或签名保障。

[save-recovery.js](../test/save-recovery.js)、[random-state.js](../test/random-state.js)、[wealth-history.js](../test/wealth-history.js) 覆盖失败保护、迁移、随机序列、动画中断及历史采样；浏览器 W / X / Y 组验证真实文件、按钮、回滚和复盘流程。完整验证入口见 [测试目录](../test/README.md)。
