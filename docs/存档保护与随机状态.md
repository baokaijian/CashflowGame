# 自动保存、续局与随机连续性

核对日期：2026-10-03；实现见 [save-state.js](../js/save-state.js)、[ui-game.js](../js/ui-game.js)、[ui-summary.js](../js/ui-summary.js)。

## 玩家操作

启动时自动读取当前浏览器中有效的本地存档并续局；没有记录则显示新游戏设置。开局页、游戏设置及全局状态条均没有手动备份、文件导入、恢复进度或历史核对入口。

游戏期间自动保存，状态条和设置显示最近成功时间或失败原因。保存前先序列化和校验，再写入 `localStorage`；失败保留上次有效记录，不更新成功时间。后续操作或页面离开时继续尝试自动保存，不能保证浏览器异常关闭前最后一步落盘。

失效或无法读取的缓存不会自动删除，启动页保留新游戏设置并提示读取失败。重新开始游戏会替换当前局；正常重置若无法删除旧记录，会保留内存对局并提示。

## 存档格式与启动校验

本地键为 `cf_save_v1`，内部格式为 `cashflow-save` v2，兼容有效的旧版 v1。它包含对局、资产负债、家庭、牌堆、待处理事件、骰子及随机进度。开局配置和主题另行保存。投资方向缓存、投资决定与独立行情的完成状态也随待处理事件保存，恢复不重新研究或重放已完成交易，见 [机会与行情](机会与行情事项.md)。

读取时在临时副本中校验格式、版本、数值、结构和危险字段，执行旧档迁移，推导账本和界面后才安装；异常时保留原局。文本上限 2,000,000 字符，玩家 1—6 人，树节点最多 150,000、深度最多 40。编码、迁移和修正辅助函数仍供内部维护与回归使用，不构成游戏界面的导入或恢复功能。

迁移不重放现金，原牌堆、报价和锁定年度缺口保留。凭据充分的旧成交成本会自动修复并记录依据；修正前原始内容可由程序保存在独立本地键，界面不提供下载或回退入口。其他旧档处理见 [旧档说明](旧档核对与修复.md)。

## 随机状态与中断掷骰

职业、组合、牌堆、骰子与洗牌共用可保存的随机状态，包括 202 抽满 25 张行情重洗。期权编号使用保存的计数器，装饰动画不消耗实际游戏随机结果。

掷骰先记录结果再播放动画。刷新后继续执行已生成结果，不重新掷骰，也不重复经过发薪；完成后清除待执行状态。旧档没有随机历史时按内容生成固定的未来序列，保留现有牌序，不声称还原过去种子。

## 复盘与历史

复盘保留财富曲线、资产负债、等级、成就、人生评级与建议，可导出 Markdown / JSON 分析报告。它们不是游戏进度文件。当前收支按所在圈计算，已售资产停止收入。

每回合观察财富，同龄合并，首个已知点独立保留；超过 60 点保留首点及最新 59 点。没有观察到的中间年份不补造。内存日志最多 300 条，本地自动存档最多 80 条，不是完整交易流水。既有 `g.recovery` 核对及补充历史数据继续保存，不因移除操作入口而删除。

## 限制与验证

没有账号、云同步、多槽或界面文件备份。清理站点数据、更换浏览器或访问地址后，原进度可能不可见。存档无服务器签名或防作弊保障。
