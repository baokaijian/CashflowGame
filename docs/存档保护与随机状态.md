# 存档保护与随机状态（D5 / D6）

实施日期：2026-09-27。

## 保存状态与备份

页面持续显示保存中、最近成功时间或保存失败。“保存与备份”入口连接设置页，提供重试、下载完整存档和导入文件；开局页也能导入。空间不足、存储被禁用、读取失败与数据校验失败均明确提示，失败不会把成功时间更新为当前时间。

自动存档先完成序列化及验证，再用一次本地写入替换旧记录；写入失败保留上次成功记录。无法读取的存档不会自动删除，可下载原始内容供核对。重新开始若无法删除旧记录，也保留当前内存对局并提示。

完整备份包含玩家、资产、负债、家庭、牌堆、待处理事件、回合状态及随机进度，与复盘的 Markdown / JSON 报告分开。下载不依赖本地存储写入成功，但当前内存状态仍须有效且未超出容量限制。内存日志最多 300 条，自动存档只保留最近 80 条，财富轨迹最多 60 点；完整备份保留当时内存中的记录，不能恢复已截断的历史。

## 导入与兼容

导入按以下顺序执行：

1. 检查文件大小、格式、版本、关键状态结构与金额类型，拒绝无效数据及危险对象键。
2. 在临时状态恢复随机源，完成时间、资产、家庭等迁移，检查账本和财务渲染；不修改正在玩的对局。
3. 展示文件名、规则、模式、回合及玩家预览；取消则保留原局。
4. 确认后先写入本地存档，再切换界面；写入失败不切换，界面恢复异常则回滚原对局和原记录。

完整存档格式为 `cashflow-save`、版本 2，仍使用 `cf_save_v1` 本地键并兼容有效的旧版 v1 存档。开局配置独立保存。文件文本上限为 2,000,000 字符，玩家最多 6 人，另有嵌套深度和节点数量限制；复盘报告、损坏文件与不支持的版本不能作为对局导入。

旧资产与家庭字段沿用已有兼容逻辑，不根据新卡片价格改写历史本金，也不重放现金收支。来源不明的历史债务或交易仍保留原有核对边界。

## 随机进度与掷骰恢复

新局将随机生成器的版本及内部状态保存到对局中，职业、组合、牌堆、掷骰和洗牌共用该随机源。未指定种子的游戏只在开局初始化一次随机状态，之后同样可保存恢复。所有牌堆恢复时重新绑定此随机源，包含 202 抽满 25 张行情后的重洗。期权编号改用可保存的计数器；纯装饰性的骰子动画不参与游戏结果。

掷骰先记录已生成的骰子结果，再播放动画。动画途中保存后恢复，会继续执行该结果；执行完成清除待执行骰子并保存，防止重新掷骰或重复结算。

旧档没有随机历史时无法反推出原种子或内部状态，因此只从此次恢复开始创建可持续保存的序列，并在日志提示。已有牌序保留；后续保存恢复延续新序列。版本不支持或数值无效的随机状态拒绝恢复。

## 仍保留的边界

- 只有一个本地自动存档槽，没有账号、云同步；可自行下载多份文件，导入会替换当前局。
- 自动保存采用短延迟合并，离开页面时尝试写入；无法保证异常退出前尚未写入的最后一步。
- 导入要求本地存储可写。浏览器禁止存储时可下载有效内存对局，但不能承诺刷新后自动恢复。
- 完整备份不等于完整历史流水，也不能补回旧档未记录的历史。
