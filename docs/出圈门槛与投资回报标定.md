# 出圈门槛与投资回报标定

核对日期：2026-09-28。参数来源为 [data-careers.js](../js/data-careers.js) 的 `YIELD`、`PRICE` 和 `LIFEBASE`，卡片数据见两版牌堆及 [data-board.js](../js/data-board.js)。这些都是游戏设计参数，不是现实市场报价或投资建议。

## 当前目标

| 条件 | 当前值 |
|---|---|
| 101 出圈 | 月被动收入严格大于月总支出 × 1.5 |
| 202 出圈 | 月被动收入严格大于月总支出 × 2.5 |
| 出圈资金 | 当时月被动收入 × 100，只领取一次 |
| 企业成就 | 自由圈累计新增企业月现金流至少 ¥20,000 |
| 自由圈生活档次 | 基础生活费用 × 1.35，个人贷款不乘倍数 |

生活费用与贷款独立列支，结清贷款让支出减少对应月供，不额外增加“生活补足”。门槛使用当前月账本；下一次年度现金结算另外考虑年中结清，因此不总等于当前月净额乘 12。公式与预览见 [还贷说明](持续生活预算与还贷.md)。

## 收益档位

| 档位 | 首付比例 | 房价口径年毛租金率 / 投入口径年净收益率 |
|---|---:|---:|
| 住宅 | 30% | 毛租金 5.0% |
| 商业物业 | 45% | 毛租金 6.0% |
| 车位 | 40% | 毛租金 5.5% |
| 自营实业 | 全额投入 | 净收益 11.0% |
| 品牌加盟 | 全额投入 | 净收益 9.0% |
| 股权投资 | 全额投入 | 净收益 10.0% |
| 固收档 | 全额投入 | 净收益 5.8% |
| 自由圈企业 | 全额投入 | 净收益 13.0% |

房产项目月利率 0.41%；毛租金由总价和年毛租金率计算，净现金流扣除未付首付部分的项目利息。机构管理费按实际合同另从正现金流扣除。首付口径年回报为 `月净现金流 × 12 / 首付`，不包含出售资本利得，也不代表资金保本。

卡片有显式例外：老破小的毛租金率 2%，允许负现金流；法拍房全款、无租金；小地块也无租金。理财档位只约束采用该 `tier` 的卡片，不覆盖所有金融资产。房产项目本金持有期间不摊还，家庭分期贷款则逐月还本，不能混用模型。

## 报价与权益收益

出售先按本人份额折算整套售价，再扣项目融资与费用。首付口径资本收益为 `资本利得 / 本人首付`，不是把整套涨价直接算成本人收入。

202 的 `m22`、`m23` 以 `cg15` 小地块为来源，权益收益参数分别为 60%、120%；`m24` 以 `cf3` 商业综合体为来源、参数 60%；`m26` 以 `cf8` 物流园为来源、参数 90%。这些参数用于同步生成整套报价，不是玩家每次交易的保证收益；实际买回成本、持仓份额和费用仍以结算时记录为准。

101 仍保留高报价事件。当前没有将全牌堆统一降价；价格是否适合更多策略应通过独立模拟评估。旧局保留原牌堆与锁定机会，新局才使用当前生成的卡片。

## 维护工具

```bash
node tools/rebalance-returns.js --dry
node test/price-calibration.js
node test/escape-difficulty.js
node test/balance-audit.js
```

`rebalance-returns.js --dry` 只预览；不带 `--dry` 会写回首付、租金、净收入、备注、相关报价与初始组合融资。它以成本及参数为基准，可重复生成；修改后要检查差异并运行对应交易和长局回归。

`PRICE.scale = 2.15` 是已经写入数据的历史价格标定元信息，游戏运行时不会再次乘它。`tools/calibrate-prices.js` 是一次性历史迁移工具，检测到 `window.PRICE` 会拒绝再次标定，不是当前日常调价入口；不要为运行它而回滚现有卡片或移除保护。

有意修改静态数据后运行 `node tools/version-assets.js`，再检查卡面文字、买入价、行情价、估值、净收益和旧存档边界。当前完整模拟见 [游戏平衡核验](游戏平衡核验.md)，不能引用已经过时的修复批次胜率。
