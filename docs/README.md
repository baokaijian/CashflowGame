## 维护规则

- 玩法行为以当前代码和可复现测试为准。修改功能时，同步对应专题与根 README；数值调整后重新生成平衡数据，记录代码基线。
- 月净额和年度结算分别解释，不再使用“年初月净额 × 12”覆盖年中结清的贷款。
- 模型简化集中放在“已知边界”，没有已承诺日期就不写成修复排期；测试通过也不等于所有路径没有缺陷。
- 已完成的四批排期、旧发薪审计、旧时间方案、单次租金修复日志已合并到对应专题；历史推导和旧数据可在 Git 历史中查阅，不再作为当前规则入口。
- [测试目录](../test/README.md) 维护验证命令和覆盖范围；这里不复制每次提交的测试数量变化。
