# 人生、精力与生活事件

核对日期：2026-09-28。本文件描述当前机制；“人生层次”是叙事，不是额外的第三条可移动棋盘。棋盘仍只有内圈和财务自由圈。

## 工资与支出曲线

工资由职业基础工资、年龄系数和精力状态推导；失业工资为零。低于 30 精力时在职工资乘 0.8。单人退休切换养老金，养老金不受低精力绩效折减。

| 年龄 | 工资系数 |
|---|---:|
| 20—27 | 1.00 |
| 28—35 | 1.15 |
| 36—45 | 1.35 |
| 46—55 | 1.20 |
| 56—59 | 1.05 |
| 60 岁起（未退休规则） | 1.00 |

生活阶段为 20—29 / 30—39 / 40—49 / 50—59 / 60 岁起，对应生活系数 0.85 / 1.00 / 1.15 / 1.05 / 0.95；40—49 岁赡养按基础工资 12%，50—59 岁按 13%，其他阶段为零。工资与支出曲线分别读取 `SALARY_CURVE`、`LIFE_STAGES`，阶段介绍不另藏一套金额。

住房、用车、用品更新和贷款独立列支，详见 [生活费用与还贷](持续生活预算与还贷.md)；子女、养老金与退休医疗见 [家庭收支](家庭收支与人生变化.md)。金额都是游戏参数，不是现实收入或费用预测。

## 精力与健康

精力上限随年龄依次为 100、95、90、85、78、70、64；自然恢复按年龄为每回合 14 / 12 / 10 / 8。考察投资机会、买入资产、求职、梦想和经营维护消耗精力，现金足够也可能无法投资。

房产与企业维护按经营类型、持有份额、同组规模和超载计算，见 [经营差异](经营差异与机构合伙.md)。期权和空头每笔每回合另耗 3 精力。

精力耗尽触发健康危机：强制休养 2 回合、康复计时 4 回合、精力恢复到上限的一半；临时月医疗额按触发时引擎月支出的 50% 记录。临时医疗只有进入实际结算年时才影响年度收支，倒计时按回合推进。休养中仍扣维护、最低为零，但不会重复触发危机无限续期；恢复行动后继续过劳仍会再次触发。

停在起点可以支付休假费用换取 28 精力；费用基于当前月支出。退休基础医疗不会因危机恢复而清零。

## 失业、求职与公益

- 失业时工资归零，领取按支出计算的离职补偿并进入求职期；生活阶段系数再乘 0.75，但贷款照付。求职基础进度要求为 2，超过 40、50 岁各增加 1；主动求职耗 12 精力，精力不足会降低效率。
- 换回合和求职不发薪、不长岁。只有经过结算日才会计算该年的失业收入，复职不追补失业工资。
- 单人退休后不再进入求职期；相关事件变为一次养老金调整。
- 公益捐赠按月总收入的 10% 计算，简化税前扣除使用 `DONATION`，同时恢复 4 精力并获得一次银翅膀。银翅膀允许内圈下一次选择双骰，用掉一次机会；不改变每格结一年规则。

税务效果仅是游戏公式，不应当作个人报税指引。

## 消费升级、等级与缺口

社会等级 L0—L7 由资产、负债、应急金和被动收入等推导；意外支出使用当前等级系数 1.00 / 1.10 / 1.25 / 1.45 / 1.75 / 2.05 / 2.40 / 2.75。

消费升级型卡全额应用系数；基础型卡仅应用涨幅的 25%，即 `1 + (系数 − 1) × 0.25`。事件金额在落格时锁定；贷款或变现不能让已经发生的账单重新报价。经常性生活费用不使用这套意外支出系数，避免混淆两类预算。

年度缺口必须解决才能继续。主动急售通常按参考估值的 80% 计算，房产扣项目融资；主动破产与偿付能力不足会出局。存款、基金的银行清算按全额，其他可清算实物资产通常半价，不能一概写成全部半价。主动认输保留资产负债，不执行破产清算。
