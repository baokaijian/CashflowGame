# 实时现金报表

核对日期：2026-10-02。报表参考用户提供的 CASHFLOW 模板，将上半部损益表与下半部资产负债表改为适合游戏账本的实时视图。没有引入 PDF 中的旧金额、旧胜利规则或未建模资产。

## 查看与刷新

游戏菜单、当前财务面板及玩家详情提供「查看现金报表」。弹窗默认选择当前玩家，从玩家详情打开则选择对应玩家；可在弹窗中切换玩家。关闭按钮、Esc 或遮罩返回仍待处理的游戏事件，不结算、不推进回合。

报表打开期间，游戏重绘会同步读取当前账本，也可点击「刷新报表」。借还款、交易、家庭变化和年度结算后的金额会更新。关闭对手财务明细时，只能查看当前行动玩家；终局后可查看全部玩家。原「财务报表总览」保留用于多人比较。

## 损益表

顶部显示现金余额、当前月净现金流与下一结算日预计年净额。收入逐项列出工资／养老金、理财利息、基金分红、房产净收入、企业收入及自由圈经营收入；支出列出生活预算、税费、子女、赡养、医疗等费用和六类个人贷款本息。

- 月净额 = 收入 − 生活及其他支出 − 当月实际月供。
- 年度列读取 `Engine.settlementPlan` 的未来十二个月计划。贷款逐月摊还，年中结清后停止扣供，尾期只扣剩余本息，所以年净额不一定等于当前月净额乘十二。
- 该计划按当前收入、持仓与生活状态预演，不预测下一次长岁或尚未发生的机会、行情、家庭事件。年度已结算金额与变化经过仍在日志中查阅。
- 自由圈不另计工资或养老金，生活费用按自由圈档次计算。逐项取整有差额时单独列出，确保合计与账本一致。
- 房产净收入已经扣除对应项目融资利息及适用机构费，不再在个人月供中重复扣除。
- 借款到账、买卖和提前还本属于一次性现金往来，反映在现金余额与持仓／负债，不能当作经常收入。

## 资产负债表

资产分别展示账面成本和当前参考估值，现金单独列出。分类如下：

| 分类 | 游戏中对应持仓 |
|---|---|
| 金融资产 | 股票、存款／理财、基金 |
| 固定资产 | 房产、土地 |
| 经营权益 | 内圈企业、自由圈企业 |
| 无形权益 | 已支付投入的特许经营权益 |
| 其他资产 | 收藏品 |

分类用于解释游戏持仓。企业权益不等于企业名下所有固定资产；品牌、商誉等没有独立建模，不虚构金额。特许经营仍使用现有游戏经营资产估值规则，不引入新折旧模型。

共有房产的账面金额、估值与融资均使用本人持有份额，逐项显示份额、首付与对应项目融资。负债包括六类个人贷款剩余本金与每套房产的项目融资余额；已扣除的融资利息不重复作为本金。个人贷款还列出当前月供和未来一年实际本息。

总资产包含现金与持仓；净资产 = 总资产 − 个人贷款本金 − 房产项目融资本金。账面净资产与 `Engine.netWorth` 一致，参考估值净资产与 `Engine.valuedNetWorth` 一致。估值是游戏参考值，不能保证按该价格成交。

期权与做空没有纳入现有引擎的净资产估值口径，报表单独列出风险头寸、权利金／建仓价和到期信息，不将其混入有价持仓合计。完整保证金和衍生品市值模型仍未实现。
