# 当前已知边界

核对日期：2026-09-28。已完成的修复排期已从当前文档移除，历史证据留在 Git 记录中。本页集中说明模型与兼容边界，不把尚未立项的增强功能写成承诺日期，也不承诺游戏不存在其他缺陷。

## 已实现的能力

发薪按格结一年并长一岁；贷款逐月计息、尾期封顶、结清停扣；生活费用独立列支；共有房产按份额出售；交易按持仓身份定位；房产可挂牌和买回；股票报价共享；理财按各笔本金兑付；子女成年减支、养老金按年数、退休医疗随年龄变化；经营有规模差异、折旧下限和机构选择；自由圈按当前持仓分红；存档失败反馈、完整备份与随机恢复均已存在。不要再将它们笼统列为“未实现”。

## 模型边界

| 范围 | 当前边界 |
|---|---|
| 时间 | 每个结算格推进一年；行动回合不等于月份。求职、康复、期权和市场抽牌按行动计时，不是连续现实日历 |
| 房产融资 | 出租房项目只付息、出售还本，未提供项目提前还贷入口；纯资本房产沿用零持有现金流，不模拟空置融资成本 |
| 房产市场 | 有行情报价和本局再次挂牌，没有买卖订单撮合、空置率、租客违约、装修年限及完整税费模型 |
| 家庭 | 没有配偶收入、抚养权或完整婚姻账本；离婚只是自由圈现金事件 |
| 养老金与医疗 | 采用游戏年数比例和年龄预算，没有真实缴费账户、地区政策、最低年限、疾病和保险报销 |
| 生活选择 | 预算由职业基准与阶段推导，不能主动降档或卖车改变预算，也没有车辆更新专用账户 |
| 经营与折旧 | 有经营类型差异；同类型同年数仍无个体维修质量差异，没有完整企业失败状态链，残值不保证成交价 |
| 机构 | 三种固定经济方案，没有主动议价、退出、违约和控制权博弈 |
| 信用 | 本局产品、借款次数及使用率模型，不含真实跨机构查询、对外担保或外部征信连接；四产品拒贷配置在当前三类产品下不可达 |
| 金融工具 | 期权按内在价值现金行权、按回合到期；做空无真实保证金和借券费用体系；理财到期由行情事件触发 |
| 自由圈 | 累计企业战绩与当前可领取收入分开；出圈奖励、特许经营、多人买断是预设玩法，不是现实估值或公司并购模型 |
| 平衡证据 | 288 个固定策略情景覆盖两版、12 职业；没有穷举最优投资、期权、做空或主动回购，不能推出总体玩家胜率 |

## 旧档核对与历史证据

旧档已具备统一的 [历史核对与修复流程](旧档核对与修复.md)。唯一成交凭据可以自动恢复成本；同一份无随机状态的旧档稳定接续未来序列；其余家庭、融资、成本、现金及已售挂牌可以凭据预览后修正。历史完整备份中的现存日志和财富记录可补入独立档案，修正前保留原档，确认记录随完整存档保存。

仍需区分程序修复和事实恢复：彻底缺失的出生、缴费、成交与随机历史不能凭空还原。没有依据时保留明确的兼容标记，不自动核销未知债务、不推测补偿现金，也不伪造开局曲线。修正入口提供处理途径，不保证用户填写的凭据真实或完整。

## 平台与产品边界

- 多人是同一设备轮流操作，没有网络房间、远程同步、账号或 AI 对手。
- 本地自动存档只有一槽，可以下载多份完整备份；不同域名、浏览器和文件地址不自动互通。
- 异常退出前尚未保存的最后一步不能保证保留；本地存储不可写时不能导入替换对局。
- 内存日志 300 条、自动存档日志 80 条、财富点最多 60 个。复盘不是完整交易流水，Markdown / JSON 报告不能当作完整存档恢复。
- 破产即出局，禁贷记录不构成复活机制；主动认输保留资产负债。
- 移动端采用响应式单棋盘视图，没有原生客户端、离线安装服务工作线程或服务器防作弊。存档是本地可编辑数据，不提供竞技可信性保证。

使用和分发还有许可边界，见 [许可说明](许可说明.md)，不要把技术上可以部署理解成已经取得商业授权。
