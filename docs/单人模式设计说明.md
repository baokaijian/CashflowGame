# 单人模式

核对日期：2026-10-03。单人可选 101 或 202，使用同一套交易、贷款、逐月净额、精力和存档机制；无自动行动的 AI 对手。

## 时间和目标

从 20 岁开始，每经过一个结算日结算一年并长一岁，正常到 65 岁结束。出圈、圆梦和企业成就会记录达成年龄，单人不会因此立即结束，仍需面对之后的支出与风险。破产或主动认输可提前结束，并生成复盘。

阶段叙事为起步期 20—27、成长期 28—35、巅峰期 36—45、平台期 46—55、冲刺期 56—60、退休期 61—65。介绍文字不参与金额计算，工资、支出和精力分别使用各自配置。

## 与多人模式的差别

| 项目 | 单人 | 多人 |
|---|---|---|
| 退休 | 61 岁开始采用缴费年数养老金，免工资相关税费，增加退休医疗 | 不启用单人退休切换；年龄模式仍到 65 岁结束 |
| 投资机会转让 | 不提供，没有付费收购机会的虚拟对手 | 可以把机会转给其他玩家 |
| 202 联合购买 | 可选择三种固定条件的机构，或全额独自买入 | 可与实际玩家共同出资 |
| 强制休养 | 逐轮确认休养，完成后仍由本人继续掷骰 | 暂停该玩家本轮行动，交给下一位 |
| 胜利与复盘 | 持续记录成就，到终局给人生评级 | 达成对应胜利条件可立即结束，或到终龄排名 |

60→61 岁先结工资年度及缴费年，再切换未来养老金。养老金为基础工资 × 45% × `min(1,缴费年数 / 41)`，不是所有人固定拿 45%。失业、退休和出圈后不新增缴费年；出圈后养老金不再叠加到资产收入。详见 [家庭收支](家庭收支与人生变化.md)。

单人 202 的共担资本、资金后盾、运营管家分别在出资、产权、收费与精力上有取舍，详见 [机构方案](经营差异与机构合伙.md)。它们不会自行议价、交易、违约或退出。

## 健康危机与休养流程

回合结束时精力在自然恢复与资产维护结算后降至零，会触发健康危机。提示页说明强制休养、临时医疗和康复回合，点击「查看休养安排」进入本轮休养。

- 单人不显示「交给下一位」。休养面板与棋盘主按钮均使用「完成本轮休养」，最后一轮为「完成休养，继续游戏」。状态条显示包含本轮的剩余轮数。
- 每次确认只推进一个回合，并结算精力恢复、维护消耗和康复倒计时；不会移动棋子、发薪、摊还年度贷款或长岁。期权到期等原有回合规则仍推进。
- 面板列出当前精力、本轮恢复与维护、完成本轮后的预计精力。强制休养结束后可继续掷骰，不代表精力已满或康复已结束；维护超过恢复时仍可能低精力或再次触发危机。
- 临时医疗只在经过发薪日／分红日时进入当年账单，按康复回合结束，不将回合数解释为「约半年」。退休基础医疗独立保留。
- 关闭面板不消耗休养轮次，棋盘主按钮仍能继续；刷新自动接续剩余休养，不重放危机或已完成轮次。连续点击不会多推进，防连点生效时面板保持显示。

休养中不能掷骰或处理棋盘事件，可查看财务与持仓。精力参数及健康机制见 [人生与精力](人生模拟改造说明.md)。

## 终局评级

| 条件（按顺序判断） | 评级 |
|---|---|
| 已破产、被判出局或主动认输 | F |
| 最迟在 60 岁实现梦想 | S |
| 60 岁之后实现梦想 | A |
| 已出圈但尚未实现梦想 | B |
| 尚未出圈、最终社会等级至少 L3 | C |
| 尚未出圈、最终社会等级低于 L3 | D |

“60 岁”包含在 S 的边界内。企业月收入累计成就会独立记录，但单人的 S / A 判定仍以梦想达成年龄为准。即使曾圆梦，之后破产也优先按 F 处理。

终局展示达成年龄、社会等级、被动覆盖度、净资产、当前结余、退休状态、健康和失业记录；不再额外发工资或摊还一遍贷款。财富复盘与完整存档的区别见 [存档与复盘](存档保护与随机状态.md)。
