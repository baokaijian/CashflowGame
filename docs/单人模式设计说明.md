# 单人模式设计说明

> **时间规则更新（2026-09-22）**：现行规则为每个发薪日 / 分红日结算一年并长一岁，玩家独立计龄；回合不长岁，无积欠、略过或退休 / 终局补结。本文涉及旧时间口径和旧测试数量的内容保留为历史记录，当前实现以 [发薪日、年龄与年度结算](结算步长与发薪日密度.md) 为准。

> 单人模式（`mode: 'solo'`）是在**年龄模式**基础上派生的一个人局：同一条 20→65 岁的时间轴，
> 同一套规则，把「和别人比谁先出圈」换成「与自己的人生赛跑」。
> 本文说明玩法流程、与既有规则的衔接方式、人生阶段的划分与财富演变机制，以及胜负判定与体验目标。
>
> 引擎侧的实现参照 [`人生模拟改造说明.md`](./人生模拟改造说明.md)（精力 / 收支生命周期 / 逆流机制）；
> 本文只讲单人模式**新增**的那部分。

---

## 一、定位与设计前提

多人局的核心张力是**博弈**：谁先出圈、谁需要合作、谁会被买断。
一旦只有一个人，这套张力全部失效 —— 但另一套更真实的张力会浮现出来：

**一个人一生的收入是有限的，而支出是刚性的、且集中在中年。**

单人模式就是把这个张力做成玩法。它不新增资源、不新增卡牌，只做三件事：

1. 把「时间」变成真正的对手 —— 收入见顶、精力衰减、父母老去、最终退休都是**必然事件**；
2. 把「其他玩家」换成**机构**，让依赖他人的规则在单人下依然成立；
3. 把结算口径从「排名」换成「评级」，衡量的是**你在什么时候做到了什么**。

## 二、玩法流程

```
开局设置                对局中（45 轮 / 45 年）                      结束
─────────              ──────────────────────────────              ────────
选「单人模式」           掷骰 → 移动 → 落格事件 → 决策 → 结算精力      65 岁退休结算
规则版本 101 / 202   →  ├ 机会格：考察（耗精力）→ 买入 / 合伙（无转让）  或 中途破产出局
输入名字              ├ 行情格：金融资产交易
（无人数选项）          ├ 意外支出：按消费档次计价（社会等级越高越贵）
                       ├ 裁员失业：进入求职期，工资归零、支出照付
                       └ 每完成一整轮长 1 岁 → 收入/支出/精力/赡养同步刷新
                         跨过阶段边界时播报「人生阶段切换」
```

与多人年龄模式**完全一致**的节奏（掷骰—移动—落格—决策—结算），只有三处不同：

| | 多人年龄模式 | 单人模式 |
|---|---|---|
| 玩家人数 | 2—6 | 固定 1 |
| 时间终点 | 65 岁同步结算，按净资产排名 | 同左，但改按**评级**结算 |
| 依赖他人的规则 | 玩家间交易 · 联合购买 · 买断 | 联合购买改由**机构合伙人**承接；转让与买断不适用（见第三节） |

### 一局里的关键决策点

单人模式**没有**「等别人先动」这种缓冲，每一轮都必须自己承担后果。三个决策反复出现：

1. **考察还是不考察** —— 考察要花 6—10 点精力（额度见附表），且**放弃不退还**（研究过了就是沉没成本）。
   精力不足时只能放弃，这条退路是零成本的。
2. **买，还是放弃** —— 现金不够时**只能放弃**；硬撑就要靠贷款，而贷款会把月供永久加进支出、
   直接抬高出圈门槛。
   ★ 单人模式**没有**「把机会转让出去」这条路 —— 遇到机会只有**买入**或**放弃**两种选择。
   多人模式则可以卖给其他玩家，这是两个模式在此逻辑上的明确分野（见第三节）。
3. **扩张到什么程度** —— 房产与企业每回合都扣维护精力（按经营类型、持有份额与组合规模计算），
   名下的东西越多，能同时推进的事越少。**过度扩张的人会被自己的资产拖到精力归零**，
   触发健康危机：强制休养 2 回合、此后每月新增半个月支出的医疗费、精力只恢复到一半。

## 三、与现有规则的衔接方式

单人模式**没有另起一套规则**。除下表列出的三项外，其余规则全部原样共用：

| 既有规则 | 单人模式下 |
|---|---|
| 101 / 202 规则版本 | 完全保留（含 202 的杠杆交易、融券做空、期权、大额现金流卡） |
| 贷款 / 提前还款（六类贷款等额本息） | 完全保留 |
| 精力系统（上限与恢复随年龄衰减、维护消耗、健康危机） | 完全保留 —— 这是单人局最主要的约束 |
| 收支生命周期（收入曲线 / 支出系数 / 赡养比例） | 完全保留 |
| 失业求职期（年龄越大越难再就业） | 完全保留；**退休后不再触发**（见下） |
| 入不敷出（月现金流为负走统一面板） | 完全保留 |
| 消费升级（社会等级 → 消费档次 → 意外支出） | 完全保留 —— 单人下等级完全由自己的积累决定，反馈更纯粹 |
| 社会等级 L0—L7 | 完全保留，并成为单人模式的**主要成绩刻度** |
| 公益捐赠 / 银翅膀 / 休假 | 完全保留 |
| **玩家间交易 / 投资卡转让** | 单人下**不适用**：遇到机会只有「买入」或「放弃」，没有转让这条路 |
| **联合购买（202 大额房产）** | → **与机构合伙人联合购买**（共担资本 / 资金后盾 / 运营管家，比较出资、净收益与管理负担） |
| **买断对手资产（202）** | 单人下不适用（没有对手），入口隐藏 |

### 三项单人专属调整

**① 退休断崖（61 岁起）**

```
61 岁之前：工资 = 基础工资 × 年龄系数（1.00 → 1.35 → 1.00）
61 岁起  ：工资 = 基础工资 × 45% × min(1, 已记录缴费年数 / 41)（养老金），且免征工资个税
```

游戏以 45% 为养老金上限，41 个已记录缴费年达到上限；不模拟现实社保个人账户或领取门槛。最新规则与旧档兼容见 [家庭收支随人生变化](./家庭收支与人生变化.md)。

这一刀之所以只用在单人模式：多人局里所有玩家在 65 岁**同步**结算，这道断崖不产生任何相对压力；
单人局里它必须被提前规划 —— 这正是「为什么必须出圈」最有力的说明。

**② 退休后不再有求职期**

61 岁后遇到「裁员失业」格，语义变为**退休返聘结束**：不进入求职期，只做一次退休金调整
（一次性少发一个月养老金），也不发离职补偿。
否则会出现「61 岁被裁 → 投简历 → 63 岁重新就业」这种明显不真实的流程。

**③ 联合购买改由机构承接（机会转让不做替代）**

单人没有其他玩家可以凑首付，202 大额房产的「联合购买」改由机构承接：

| 替代 | 规则 | 现实对应 |
|---|---|---|
| 机构合伙 | 共担资本出 50%、资金后盾出 70%；运营管家出 50% 并收正现金流 20% 管理费，换取较低精力占用 | 在首付、收益和精力之间取舍；实际条件见经营差异说明 |

机构合伙保留了原有的**取舍**结构（买得起，代价是收益减半），而不是单纯的替代品 ——
这与多人局的「合作」在结构上是同构的。

> **为什么机会转让不做替代？**
> 把一张自己吃不下的投资机会卖出去换现金，现实里并没有对应场景 ——
> 机构完全可以自己找项目，不必为你「看过一眼」付费。
> 与其硬造一个「按标价折现」的机制，不如承认这条路不存在。
> **单人模式遇到机会只有「买入」或「放弃」两种选择；多人模式的「卖给其他玩家」照常保留。**

## 四、人生阶段的划分与财富演变机制

### 4.1 六个阶段

阶段边界与 `SALARY_CURVE` 对齐；退休期起点与 `SOLO.retireAge` 一致。

| # | 阶段 | 年龄 | 现实标签 | 核心矛盾 |
|---|---|---|---|---|
| 1 | 起步期 | 20—27 | 职场新人 | 攒下第一桶金 |
| 2 | 成长期 | 28—35 | 立业成家 | 把工资变成资产 |
| 3 | 巅峰期 | 36—45 | 收入黄金十年 | 趁高峰期完成原始积累 |
| 4 | 平台期 | 46—55 | 见顶回落 | 守住已有资产并完成出圈 |
| 5 | 冲刺期 | 56—60 | 最后一班车 | 退休前达成被动收入覆盖 |
| 6 | 退休期 | 61—65 | 没有工资，只有资产 | 靠资产活着 |

### 4.2 阶段表里**不含任何业务数值**

这是必须强调的一条实现约定：

> `SOLO_STAGES` 只写叙事（阶段名 / 年龄区间 / 现实标签 / 核心矛盾 / 一段说明）。
> 收入倍数读 `SALARY_CURVE`、支出系数与赡养比例读 `LIFE_STAGES`、精力读 `ENERGY`。

原因很直接：阶段卡与财务报表**同时显示在界面上**。如果阶段表自带一份数值，
迟早会出现「阶段说 ×1.35、工资表说 ×1.20」这种自相矛盾 ——
而玩家看到两处不一致时的第一反应是「系统算错了」，不会去想是哪张表写错了。
回归里有一条断言专门守这件事：**阶段表不得含业务数值字段**。

### 4.3 财富演变机制：三张曲线如何叠加

一个人一生的可支配现金流，由四条曲线共同决定：

```
月现金流 = 基础工资 × 收入曲线(年龄)
         − 基础税负 × 收入曲线(年龄)        ← 养老金阶段为 0
         − 生活支出 × 支出系数(年龄)
         − 实发工资 × 赡养比例(年龄)
         − 各项贷款月供（固定，直到还清）
```

四条曲线在现实中**方向并不一致**，这正是单人模式的全部张力：

- **收入先升后降**：1.00 → 1.35（36—45 岁峰值）→ 1.00（60 岁）
- **支出在中年隆起**：0.85 → 1.15（49 岁）→ 0.95，赡养在 49—59 岁再叠 12%—13%
- **精力单调下降**：上限 100 → 64，每回合恢复 14 → 8
- **贷款月供终身不变**：本作 1 轮 = 1 年、还款按月计，45 轮还不完一笔房贷（见 README 已知约束）

### 4.4 实测轨迹（货运司机，无额外负债）

| 年龄 | 阶段 | 收入倍数 | 工资 | 赡养 | 生活系数 | 总支出 | **月现金流** | 精力上限/恢复 |
|---|---|---|---|---|---|---|---|---|
| 20 | 起步期 | 1.00 | 2,500 | 0 | 0.85 | 1,562 | **+938** | 100 / 14 |
| 28 | 成长期 | 1.15 | 2,875 | 0 | 0.85 | 1,631 | **+1,244** | 100 / 14 |
| 36 | 巅峰期 | 1.35 | 3,375 | 0 | 1.00 | 1,811 | **+1,564** | 95 / 12 |
| 45 | 巅峰期 | 1.35 | 3,375 | 405 | 1.15 | 2,304 | **+1,071** | 90 / 12 |
| 46 | 平台期 | 1.20 | 3,000 | 360 | 1.15 | 2,190 | **+810** | 85 / 10 |
| 56 | 冲刺期 | 1.05 | 2,625 | 341 | 1.05 | 2,044 | **+581** | 70 / 8 |
| 60 | 冲刺期 | 1.00 | 2,500 | 0 | 0.95 | 1,621 | **+879** | 70 / 8 |
| **61** | **退休期** | — | **1,125** | 0 | 0.95 | 1,161 | **−36** | 64 / 8 |

读这张表可以看清单人模式想讲的全部内容：

1. **收入峰值与支出峰值重叠在 36—45 岁** —— 账面上最有钱的十年，恰恰是攒不下钱的十年；
2. **现金流最低点是 56 岁**（+581）—— 收入已回落、赡养仍在高位，冲刺期的「最后机会」是字面意思；
3. **61 岁变成负数** —— 这就是退休断崖。**没有被动收入的人，退休后每个月都在消耗积蓄**；
4. 而真正会让人破产的不是 −36 这个数字本身，是它**无法靠努力扭转**：61 岁之后不能再通过加班补回来。

> 12 个职业在默认轨迹上一生现金流为正（`test/career-cashflow-scan.js`），
> 即「不作死就不会破产」；但退休期转负是**所有职业共同**的结果，这是设计要求，不是标定失误。

## 五、胜负判定与体验目标

单人模式**不排名次** —— 没有可比的人，只能与时间比。结局按「什么时候做到了什么」自上而下判定：

| 结局 | 判据 | 评级 | 含义 |
|---|---|---|---|
| **人生赢家** | **60 岁前**出圈并实现梦想 | **S** | 财富自由在窗口期内完成，此后不工作也由资产支撑 |
| **大器晚成** | 实现梦想，但晚于 60 岁 | **A** | 赢了结果，输了时间 |
| **自由未圆梦** | 出圈但到退休仍未实现梦想 | **B** | 有了自由，但自由没落到具体的事上 |
| **仍在老鼠赛跑** | 未出圈，但最终社会等级 ≥ L3 | **C** | 差一步 |
| **仍在老鼠赛跑** | 未出圈，且最终社会等级 ≤ L2 | **D** | 一生都在用时间换钱 |
| **中途出局** | 破产 / 主动认输 | **F** | 现金流断裂 —— 唯一不可逆的失败 |

- **60 岁门槛**直接来自财富流原规则（「60 岁钟声响起前进入顺流层并实现梦想」）。
  判定用的是**严格早于或等于** 60 岁（含）。回归里专门构造了「恰好 60 岁」的边界用例。
- **C 与 D 的分界（社会等级 L3）**区分的是「差一步」与「没能摆脱用时间换钱」——
  两者都不算成功，但确实不是一回事，不该给同一个评价。
- **F 单独一档**：破产比任何一种「没做到」都更严重，因为它终结了后面的所有可能性。

### 一处刻意的改动：完成梦想**不结束**对局

多人模式里，谁先买到梦想对局立刻结束（`E.win`）。
单人模式下改为**只记录达成年龄**，对局继续到 65 岁。理由有两层：

1. 单人模式的目标是「完整走完一生」。若 48 岁买到梦想就收场，
   玩家会看不到财务自由圈的后续人生（企业、更多梦想）以及最关键的退休期；
2. 这更贴近财富流原意：进入顺流层后赚钱更快，但**能否守住仍取决于后续决策**。

因此「什么时候达成的」被记在 `p.achievements` 里（含年龄与类型），留到 65 岁结算时评档。
为防止玩家为一个已经拥有的梦想反复付钱，重复购买会被拦下。

### 结算页

不排名次，只回答「这一生走到了哪一步」：

- **评级 + 结局标签**（S/A/B/C/D/F，配色随档位变化）
- **关键时间点**：出圈年龄 / 圆梦年龄 / 赢家门槛 / 结束时间
- **最终状态**：社会等级、被动收入覆盖度、净资产、月现金流、退休状态、健康危机与失业次数
- 未达 L6 时，直接给出**距财务自由还差的月被动收入** —— 这是最值得复盘的差距

**无论怎么结束都会产出结算。** 破产走的是 `checkLastStanding` 而不是「到 65 岁」，
所以结算结果被抽成独立的 `buildSoloResult(g)`，两条路径都调用它 ——
否则最常见的那条失败路径（中途破产）会没有任何总结可看。

## 六、参数速查

`SOLO`（`js/data-careers.js`）：

| 参数 | 值 | 说明 |
|---|---|---|
| `retireAge` | 61 | 退休年龄，此后收入改为养老金 |

| `winAge` | 60 | 人生赢家的年龄门槛 |

| `partnerEnergy` | 0.60 | 机构合伙时玩家承担的精力比例 |

依赖曲线（改动后**必须重跑** `node test/solo-mode.js`）：

| 曲线 | 位置 | 关键值 |
|---|---|---|
| 收入 | `SALARY_CURVE` | ≤27 → ×1.00 · ≤35 → ×1.15 · ≤45 → ×1.35 · ≤55 → ×1.20 · ≤59 → ×1.05 · 之后 ×1.00 |

| 失业求职 | `UNEMPLOYMENT` | 基础 2 回合 · 40 岁以上 +1 · 50 岁以上再 +1 · 每次求职耗 12 点精力 |

## 七、验证

```bash
node test/solo-mode.js      # 78 项断言，退出码 0 = 全通过
```

覆盖范围：

- **人生阶段**：6 段、随年龄单调不降（不会回跳）、逐段核对边界年龄、
  退休期起点与 `retireAge` 对齐、**阶段表不含业务数值字段**、切换播报且不重复播报
- **退休断崖**：61 岁标记翻转、足额缴费者养老金 = 基础工资 × 45%、**养老金免征个税**、
  退休后收入不再衰减、**多人年龄模式完全不受影响**（65 岁不退休、税负未清零）、
  退休后遇到裁员不进入求职期且不发离职补偿
- **单人下只有买入或放弃**：引擎里**彻底不存在**转让能力（不是只把按钮藏起来）、
  配套报价函数与 `orgBuyRate` 配置均已移除、放弃一张买不起的机会不产生任何现金变化且能正常收尾；
  **同时断言多人模式的 `sellOpportunity` 照常可用**（两个模式确实区分处理）
- **机构合伙**：出资 = 首付 × 50%、现金流按比例切分、只扣自己那部分、精力按比例、
  资产标注「与机构共有」、**现金不足时拒绝且不产生任何扣款**
- **结局与评级**：五种结局逐一构造（含「恰好 60 岁」边界）、未出圈时 C/D 分档、
  `soloOutcome` 不自带 `grade`（避免两套口径）、**走真实的 `endSolo` 链路**并核对
  `g.soloResult` / `g.winner` / 关键时间点、未达成时 `winner` 必须为 `null`
- **单人长局回归**（101 与 202 各一局，45 轮）：无负现金、无 NaN、无卡死、精力不破 0、
  阶段推进 ≥ 4 次、**无论怎么结束都产出结算**、评级与结局严格对应

浏览器侧另有 48 项断言（`test/browser-behavior.js` 之外的单次探针，已随验证结束清理）：
开局页模式选项与「切回多人后完整还原」、顶栏与财务面板的阶段呈现、
单人下玩家间交易入口隐藏而通用入口保留、
卡片弹层在单人下**不出现任何「转让」入口**（只有放弃 / 买入，202 大额房产另有机构合伙开关）、
机构合伙的金额与引擎实扣一致且勾选后按钮文案同步变化、结算页六个区块与导出 / 复盘入口。

## 八、尚未采纳的缺口

诚实列出单人模式下仍然不真实的几处，供后续判断：

1. **配偶与婚姻结构仍是静态的**。子女支出已按各自年龄变化，但配偶收入、双职工、离婚后的抚养费仍未进入模型，
   而本作只把离婚做成逆流事件，不改变家庭收支结构。
2. **养老金已按记录的缴费年数计算**，但未模拟缴费基数、个人账户、最低年限或自愿续缴；旧档年数为明确标注的兼容估计。
3. **房产再次挂牌已实现**。已出售的房产保留实体编号、份额和历史，下一回合起可从投资机会进入挂牌市场买回；旧存档中已删除的历史房产无法追溯重建。详见 [资产报价与交易结算](./资产报价与交易结算.md)。
4. **退休基础医疗已随年龄增加**，并与健康危机临时医疗分列；尚未区分不同疾病、保险报销与个体健康史。详见 [家庭收支随人生变化](./家庭收支与人生变化.md)。
5. **机构已有经济条件差异**，共担资本、资金后盾和运营管家具有不同出资、收费和精力分工。主动退出、违约与议价仍未模拟。详见 [经营差异与机构合伙](./经营差异与机构合伙.md)。
6. **单局只有一个人生**。真正的「人生模拟」通常允许在某个节点重来，
   而本作是一次性的 —— 这也是评级制的意义所在（没有第二次）。
