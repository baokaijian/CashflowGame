# 投资机会与行情事项

核对日期：2026-10-03。每次投资机会仍只完成一笔投资决定；两类方向允许来回比较，202 同时抽到的行情是独立待处理事项。

## 操作规则

- 101 可比较小额理财与大额置业；202 可比较杠杆交易与大额现金流。投资卡上点击「比较另一方向」返回选择页，不放弃当前投资，也不丢失已看过的卡片。
- 每类方向在本次机会中只抽一张卡，首次考察按原配置扣研究精力。再次查看原方向使用缓存，不重新抽牌、不重复扣研究精力。尚未考察的另一方向仍需研究精力；精力不足不会扣款或换牌。
- 最终只做一笔买入、联合／机构购买、挂牌承接、机会转让或放弃决定。完成后锁定投资部分，不能在同一次机会再买另一类项目。
- 202 的投资和行情分别显示「待处理／已完成」。买入或放弃投资后，若行情未处理，继续显示行情；先完成行情则回到尚未决定的投资。所有事项完成后才解除待处理事件，允许结束回合或出圈。
- 行情中的卖出、兑付或行权可逐笔操作；点击「完成市场结算」才表示已经做完该行情决定。没有可交易持仓时也需确认完成。还没确认前可返回投资，行情保持待处理。
- 独立行情格仍只处理自身行情，不额外生成投资事项。101 没有同时抽到的行情，完成投资决定即可结束该环节。

行情报价按当前持仓重新生成交易选项。因此先买入汽车经销店，再处理同次机会的产业资本并购时，可以按该企业实际投入成本生成收购报价；先确认结束行情，再买入的资产不会追溯获得一次已经结束的交易机会。租金冲击、强制平仓等已执行效果只记录一次，反复查看或恢复不会重复施加。

## 保存与旧档

当前卡片、各方向已考察的卡片、投资决定、行情确认状态及返回位置随自动存档保存。买入之后刷新，只继续未处理的行情；完成行情之后刷新，只继续尚未决定的投资，不重放资金或研究费用。

旧的待处理机会会接续其中仍保存的投资卡和行情，已看过的当前卡片成为缓存。旧版已经清除的机会、交易选择或行情历史没有完整凭据，不能凭空恢复或补发历史交易；不会推测追加资产或现金。

## 实现与验证

`Act.opportunityState` 初始化 `pending.flow`，保存卡片缓存、投资决定与行情状态；`chooseDeck` 复用已考察方向。`UiPending` 分别推进投资和行情。行情子事件通过 `returnOpportunity` 保留原投资事项，完成或返回时接回原状态。普通、机构、联合、挂牌和转让路径共同遵循单笔投资决定。

`SaveState` 校验新增进度及行情返回数据。弹窗旧按钮失效后不能继续提交，已完成的投资也不能再次买入或转让。

[opportunity-flow.js](../test/opportunity-flow.js) 验证缓存、单笔执行、存档及旧状态接续；[浏览器行为探针](../test/browser-behavior.js) AH、AI 组验证汽车经销店与并购、买入／放弃后保留行情、先行情、方向比较、重复按钮、保存恢复及完成顺序。原机构、挂牌、联合购买和贷款返回组继续验证对应路径。
